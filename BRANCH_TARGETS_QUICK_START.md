# Branch Targets - Quick Start Guide 🎯

---

## 🚀 How to Access

### For Admin & President:

1. **Login** to your dashboard
2. Look at the **left sidebar**
3. Click on **"Branch Targets"** (Trophy icon 🏆)
   - It's located between "Reports" and "Settings"

**Direct URL:** `http://localhost:5173/settings/branch-targets`

---

## 📝 How to Set Targets

### Step 1: Select Period
```
1. Choose Month (dropdown)
2. Choose Year (dropdown)
```

### Step 2: Enter Targets for Each Branch

For each branch, enter targets for:
- **Applicants** - Total new applicants target
- **Medical** - Target for medical stage
- **Transfer to HO** - Target for HO transfers
- **Deployed** - Target for deployments

### Step 3: Save
Click **"Save All Targets"** button at the bottom

---

## 📊 Where to See the Results

### Admin/President Dashboard:
1. Go to main **Dashboard** (`/`)
2. Look for **"Goal Progress"** widget
3. You'll see:
   - Total Applicants progress
   - Total Medical progress
   - Total Transfer progress
   - Total Deployed progress
   - Overall progress percentage

### Branch Manager Dashboard:
1. Branch Manager logs in
2. Goes to **Dashboard**
3. Sees **"Goal Progress"** widget with:
   - Their branch-specific targets
   - Current progress against targets
   - Visual progress bars

## ⚡ Quick Tips

1. **Monthly Planning**: Set targets at the start of each month
2. **Realistic Targets**: Base targets on historical data and capacity
3. **Regular Updates**: Review and adjust targets mid-month if needed
4. **Team Communication**: Share targets with Branch Managers
5. **Progress Tracking**: Check Goal Progress widget daily

## 🆘 Troubleshooting

### Can't see "Branch Targets" in sidebar?
- ✅ Make sure you're logged in as **Admin** or **President**
- ✅ Refresh the page (Ctrl+R)
- ✅ Clear browser cache

### Targets not showing in Goal Progress?
- ✅ Make sure you saved the targets
- ✅ Check you selected the correct month/year
- ✅ Refresh the dashboard

### Save button not working?
- ✅ Check all fields are filled with numbers
- ✅ Make sure numbers are greater than 0
- ✅ Check your internet connection
